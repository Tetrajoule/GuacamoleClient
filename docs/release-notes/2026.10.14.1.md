# GuacamoleClient 2026.10.14.1

Stable release of the [Tetrajoule/GuacamoleClient fork](https://github.com/Tetrajoule/GuacamoleClient), including the native clipboard improvements and a corrected MSIX distribution.

## Clipboard improvements

- Native WinForms Ctrl+V forwards Windows clipboard text to the active Guacamole session, including servers accessed over HTTP.
- Clipboard streams end after their text blobs without waiting for success ACKs that Guacamole's RDP implementation does not send.
- Remote paste shortcuts use numeric key states required by the Guacamole protocol.
- Active-session checks, native gesture validation, clipboard-read retries, serialized paste requests, and content-free diagnostics are preserved.
- Rejection, send failure, cancellation, disconnect, and session replacement suppress pending pastes. Ended streams are not terminated twice during cancellation.

## Packaging and publishing

- Fixes the inherited MSIX workflow, which could report success while packaging no executable and retaining version `0.1.9.0`.
- MSIX now contains the published WinForms executable, application libraries, and self-contained .NET runtime. Its manifest and update metadata use the release version.
- Adds a package verification gate that rejects MSIX files with missing payloads, incorrect versions, unresolved executable paths, or incorrect update metadata.
- Fork MSIX builds use their own package identity and publisher. MSIX remains unsigned; installation and upgrade with a trusted signature remain a follow-up check.
- Release workflows use the `published` event so publishing a draft or creating a release with initial assets also starts packaging.
- Download URLs, ClickOnce providers, and update feeds point to the publishing repository.
- CI runs .NET and JavaScript tests across Windows, Linux, and macOS. macOS uses the supported macOS 15 Intel image.

## Verification

- WinForms and Avalonia Release builds passed without warnings or errors.
- .NET tests: 159 passed, 6 skipped. JavaScript tests: 14 clipboard tests and 7 monitor-layout tests passed.
- The corrected self-contained MSIX was built locally with Windows SDK MakeAppx and passed executable/runtime, manifest-version, and update-feed checks.
- Release workflows passed `actionlint` validation.
- Live WinForms/RDP checks passed for Unicode/emoji, multiline text, five rapid pastes, a 55,000-character payload, remote-to-local copying, and paste/copy after reconnect.
