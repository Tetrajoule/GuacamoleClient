# GuacamoleClient 2026.10.14.0

Stable release of the [Tetrajoule/GuacamoleClient fork](https://github.com/Tetrajoule/GuacamoleClient).

## Highlights

- Adds reliable native Windows text clipboard forwarding to the WinForms client, including Guacamole servers accessed over HTTP.
- Fixes Ctrl+V transfers that stalled while waiting for clipboard acknowledgements that Guacamole's RDP implementation does not send.
- Fixes synthesized remote paste shortcuts by sending numeric key-down/key-up states required by the Guacamole protocol.
- Ends each clipboard stream before dispatching remote paste, matching the Guacamole web client's text transfer behavior.
- Preserves active-session checks, native gesture validation, clipboard-read retries, serialized paste requests, and clipboard diagnostics without logging clipboard contents.
- Prevents pending paste requests from reaching a replaced, disconnected, or different client and avoids duplicate stream termination during cancellation or send failure.

## Release infrastructure

- Release artifacts, ClickOnce installation URLs, update metadata, and the download site now use the repository that publishes the release.
- CI runs the clipboard bridge and monitor-layout JavaScript regression suites alongside the .NET tests on Windows, Linux, and macOS.
- macOS CI and packaging use the supported macOS 15 Intel image instead of the queued `macos-latest` runner pool.
- App projects build sequentially where they share project references. CI tests the explicit projects instead of requiring DesktopBridge support on every runner.

## Verification

- WinForms and Avalonia Release builds completed without warnings or errors.
- .NET unit tests: 159 passed, 6 skipped.
- Clipboard JavaScript regression tests: 14 passed.
- Monitor-layout JavaScript regression tests: 7 passed. Release workflows passed `actionlint` validation.
- Live WinForms/RDP checks passed for German/Japanese/emoji text, multiline text, five rapid pastes, a 55,000-character payload, and paste after reconnect.
- Small and large remote-to-local transfers and the reconnect roundtrip passed exact Windows clipboard comparisons.
